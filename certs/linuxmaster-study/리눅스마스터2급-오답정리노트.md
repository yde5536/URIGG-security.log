# 리눅스마스터 2급 오답 정리 노트

> 10/4\~10/23의 퀴즈·자체 모의고사·교재 기출·오답 총집합에서 틀린 것을 **개념별로** 묶었다.
> 같은 개념을 여러 번 틀렸으면 한 줄로 합쳤다. **⚠ = 세 번 이상 틀림.**
> 읽는 법: **내가 고른 답(함정)** 칸을 먼저 보고, 왜 끌렸는지 떠올린 다음 **정답**과 **왜**를 읽는다.
> 시험 전날(10/30)과 시험 당일 아침(10/31)에 이 노트만 본다.

## 0. 시험장에서 지킬 것

1. **부정 발문(틀린·아닌·않은·거리가 먼)**: 보기마다 O·X를 적고 **X를 고른다.** 옳은 보기를 골라서 틀린 것이 8개 이상이다.
2. **순서 문제(mount, ln -s, cal, cron)**: 머릿속으로 말하지 말고 **칸을 손가락으로 짚으며** 맞춘다.
3. **서브넷**: 네트워크 / 쓸 수 있는 범위 / 브로드캐스트 **세 줄을 적고** 고른다. 경계 숫자(.64, .96, .128, .192)는 답이 아니다.
4. **예전에 틀린 답이 또 눈에 들어오면 의심한다.** 같은 오답을 다시 고른 것: ksh, netstat, gzip -r, lp -r, DQDB, ssh -u.

## 1. 가장 많이 틀린 것 (먼저 외울 것)

| 개념 | 자주 고른 함정 | 정답 | 한 줄 |
|---|---|---|---|
| ⚠ 전체 사용자 환경 변수·시작 프로그램 | ~/.bash_profile, /etc/bashrc | **/etc/profile** | **/etc/ = 모두, ~/ = 나 한 명.** profile = 환경 변수·PATH, bashrc = alias·함수 |
| ⚠ ssh·telnet 계정 지정 | -u, `telnet 계정@호스트` | **-l 계정** | **l = login name.** -u 없음. **telnet은 -l만**, ssh는 -l과 @ 둘 다 |
| ⚠ tar 옵션 | t(목록)를 풀기로, r·x 혼동 | **x 풀기 / c 새로 묶기 / t 목록 / r 끝에 추가** | 풀 위치 **-C**(대문자). z gzip, j bzip2, **J xz** |
| ⚠ 서브넷 브로드캐스트·게이트웨이 | 다음 경계(.96, .192, .129), 첫 주소(.64) | **구간 끝 = 다음 경계 − 1** | 블록 = 256 − 마스크 끝 숫자. 양 끝(네트워크·브로드캐스트)은 쓸 수 없음 |
| ⚠ HISTSIZE / HISTFILESIZE | 양쪽 다 반대로 고름 | **FILE 있으면 파일(~/.bash_history), 없으면 메모리** | history 명령·↑↓로 보이는 개수 = HISTSIZE |
| ⚠ touch -c | ctime만 변경, 크기 0 파일 생성 | **파일이 없으면 아무것도 안 만듦** | c = no create |
| ⚠ 쿼터 명령 | setquota, edquota, quota 혼동 | **quotacheck(파일 생성) → edquota(vi로 한도) → quotaon → repquota(전체 표)** | setquota = 명령줄에 숫자로, quota = 한 사용자 |
| ⚠ GRUB 2 설정 반영 | systemctl restart grub, `-o /etc/default/grub` | **/etc/default/grub 수정 → `grub2-mkconfig -o /boot/grub2/grub.cfg`** | -o = 만들어 낼 **출력** 파일. 원본을 덮으면 안 됨 |
| ⚠ mount 순서 | `mount -t ext4 /data /dev/sdb1` | **`mount -t 형식 장치 디렉터리`** | cp처럼 **있는 것 → 붙일 곳**. -o는 옵션(ro, loop) |
| ⚠ MAC 주소 확인 | route, netstat | **ifconfig** (HWaddr·ether) | arp = **다른** 호스트의 IP↔MAC |
| ⚠ top 키 | r ↔ k 반대로, q·n | **k = kill(시그널), r = renice(NI)** | q 종료, M 메모리순. top에 **디스크 사용률은 없음** |
| ⚠ 특수 권한 없는 파일 | /bin/mount, /tmp | **/dev/null, /etc/shadow** | mount·su·passwd = SUID, /tmp = Sticky |

| 특정 사용자 환경 변수 | /etc/profile | **~/.bashrc** | 반대 방향으로 틀린 경우. 사용자별 = ~/ |

| ↑↓로 이전 명령 불러오기 | 명령행 편집, Alt | **히스토리 기능, 방향키** | 편집 = ←→로 지금 줄 고치기, 완성 = Tab |

| 셸이 나온 순서 | csh → bash → tcsh | **csh → tcsh → bash** | tcsh = csh 개선판(1983), bash = 1989 |
| `echo $SHELL` | 지금 쓰는 셸 | **로그인 셸(/etc/passwd에 적힌 것)** | 지금 쓰는 셸 확인 = **ps** (chsh 아님) |
| root가 kaituser 셸 변경 `chsh ( )` | -u kaituser | **kaituser** | chsh -u 없음. `$ chsh -s ...` + "Shell changed." = 일반 사용자의 chsh |
| ⚠ 기존 사용자 셸 변경 | `usermod -c` | **`usermod -s`** | s = shell, c = comment |
