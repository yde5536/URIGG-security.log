# 네트워크 첫걸음 #2 - IP 주소

> 📝 블로그 원문: [[네트워크 첫걸음 #2 - IP 주소]](https://urigg-security.tistory.com/entry/%EB%84%A4%ED%8A%B8%EC%9B%8C%ED%81%AC-%EC%B2%AB%EA%B1%B8%EC%9D%8C-2-IP-%EC%A3%BC%EC%86%8C)

이전 편에선 데이터는 **패킷**으로 쪼개져 이동하고, 패킷의 **헤더**에는 받는 주소와 보내는 주소, 조각 번호가 택배 송장처럼 적혀있다고 배웠다. 이번 편에서는 그 **주소**가 어떻게 이루어져 있는지를 다룬다.

## 1. IP 주소란 무엇인가

IP 주소는 **네트워크에서 기기를 찾아가기 위한 주소**이다. IP는 **Internet Protocol**의 약자로, 1편 프로토콜 목록에서 "IP : 주소를 붙이고 길을 찾는 약속"이라고 소개했던 그 IP이다. 즉 "IP라는 약속에서 정한 주소 형식"이 IP 주소이다.

### IP 주소의 생김새

```
192.168.0.15
```

IP 주소는 **0부터 255까지**가 들어갈 수 있는 **숫자 4칸**이 점(`.`)으로 나뉘어 있는 형태이다. `300.1.1.1`은 숫자 하나가 255를 넘기 때문에 IP 주소가 될 수 없다.

### 왜 숫자 4칸인가?

컴퓨터는 2진법을 사용하기 때문에 모든 것을 0과 1로 다룬다. 이 0 또는 1 한 자리를 **비트**라고 한다. IP 주소의 한 칸은 **8비트**로 표현되는데, 비트 8개 각각에 0과 1이 올 수 있으니 2를 여덟 번 곱한 **256가지**를 나타낼 수 있다. 컴퓨터에서 수는 0부터 세기 때문에 한 칸의 범위가 0부터 255까지가 된다. 그리고 이런 칸이 4개이므로, IP 주소 하나는 8 × 4 = 32비트가 된다. 이 32비트짜리 주소 방식을 **IPv4**라고 하고, 우리가 쓰는 대부분의 주소가 이것이다.

32비트로 만들 수 있는 주소는 2의 32제곱인 약 43억 개이다. 세계 인구는 80억이 넘고, 한 사람이 폰·노트북·태블릿 등 기기를 여러 대 쓰기 때문에 IP 주소가 모자라게 되는 문제가 생긴다. 이 문제를 해결하려고 나온 것이 **사설 IP**와 **NAT**이다.

## 2. 공인 IP와 사설 IP

### 공인 IP - 인터넷에서의 진짜 주소

**전 세계에서 딱 하나뿐인 주소**이다. 통신사(KT, LG유플러스, SK브로드밴드 등)가 나눠준다. 인터넷에서 나를 찾아오거나 내가 찾아가려면 이 주소가 필요하다.

### 사설 IP - 우리 집 안에서만 쓰는 주소

우리 집 **LAN 안에서만 통하는 주소**이다. 공유기가 나눠준다.

공인 IP는 아파트 단지 주소이고, 사설 IP는 단지 안의 동·호수라고 생각하면 이해가 쉽다. 택배를 보낼 때 "서울시 OO구 OO동 OO아파트"까지는 전국에서 유일해야 하지만, 동·호수는 단지 안에서만 구분하면 되므로 같은 동·호수가 다른 아파트에 똑같이 있어도 괜찮다.

### 왜 우리 집 기기는 192.168로 시작할까

"이 범위는 사설 IP로만 쓰자"고 **전 세계가 약속해둔 주소 대역**이 있다.

```
10.0.0.0        ~ 10.255.255.255
172.16.0.0      ~ 172.31.255.255
192.168.0.0     ~ 192.168.255.255
```

집에서 쓰는 공유기들은 보통 이 중 **192.168.0.x** 또는 **192.168.1.x**를 기본값으로 사용한다. 그래서 우리 집 폰도, 옆집 폰도, 학교 컴퓨터도 전부 192.168로 시작하는 경우가 많다. 서로 겹쳐도 각자 다른 LAN 안에서만 쓰는 주소라서, 옆집의 `192.168.0.15`와 우리 집의 `192.168.0.15`는 아무 상관이 없다. 101동 101호가 전국에 수없이 많아도 문제가 없는 것과 같다.

이 방식 덕분에 주소 부족 문제가 크게 줄어들었다. 집마다 공인 IP 하나만 있으면, 그 안에서는 사설 IP로 수십 대를 연결할 수 있기 때문이다.

## 3. NAT - 공유기가 주소를 바꿔준다

### 사설 IP로는 인터넷에 못 나간다

여기서 의문이 생긴다. 사설 IP는 우리 집 안에서만 통하는 주소인데, 그럼 내 폰은 어떻게 유튜브에 접속할까? 유튜브 서버가 사설 IP로 답장을 보내려 해도, 전 세계에 그 주소를 쓰는 집이 수백만 곳이라 어디로 보낼지 알 수 없다. 그래서 인터넷의 라우터들은 사설 IP가 적힌 패킷을 아예 전달하지 않고 버린다.

### 공유기가 하는 일

그래서 공유기가 주소를 바꿔서 내보낸다. 여기서 주소를 바꾸는 이 기술을 **NAT(Network Address Translation, 네트워크 주소 변환)** 라고 한다.

```
[내 폰]                [공유기]                    [유튜브 서버]
192.168.0.7  ──→  보내는 주소를 바꿔치기  ──→   211.xxx.xxx.xxx에서 온 요청
                  (우리 집 공인 IP로)
                        ↓
            "누가 요청했는지" 표에 적어 둠
                        ↓
192.168.0.7  ←──   표를 보고 원래 기기에게  ←──   응답
```

- ① 내 폰(192.168.0.7)이 공유기에 요청을 보낸다.
- ② 공유기는 보내는 주소를 공인 IP로 바꾸고, "폰이 보낸 요청"이라고 표에 기록한다.
- ③ 공유기가 유튜브 서버에 요청을 보낸다. 서버 입장에서는 211.xxx.xxx.xxx(우리 집 공인 IP)에서 온 요청으로 보인다.
- ④ 유튜브 서버가 공유기에게 응답을 보낸다.
- ⑤ 공유기가 표를 확인하고 응답을 폰에게 전달한다.

NAT 덕분에 집 안의 폰, 노트북, TV가 공인 IP 하나를 나눠 쓴다. 이것이 한국에서 이 기계를 "공유기"라고 부르는 이유이다. 1편에서 공유기는 **AP + 스위치 + 라우터**가 합쳐진 기계라고 배웠었다. 여기에 **NAT**라는 역할이 하나 더 있는 셈이다.

## 4. 특별한 주소, 127.0.0.1

`127.0.0.1`은 **"나 자신"을 뜻하는 특별한 주소**이다. 어느 컴퓨터에서 치든 그 컴퓨터 자신을 가리킨다. `localhost`라는 이름으로도 부른다. 이 주소로 보낸 데이터는 **랜선이나 와이파이로 나가지 않는다.** 컴퓨터 안에서만 돌다가 자신에게 돌아온다. 그래서 인터넷이 끊겨 있어도 동작한다. 이 주소는 주로 **개발할 때** 쓴다. 내 컴퓨터에 웹사이트를 만들어 놓고, 밖에 공개하기 전, 나 혼자 확인해 볼 때 `127.0.0.1`로 접속한다.

## 5. IPv4와 IPv6

앞에서 **IPv4** 주소가 약 43억 개뿐이라 모자라다고 배웠다. 사설 IP와 NAT는 이 문제를 미루는 방법이지, 근본적인 해결책이 아니다. 그래서 나온 것이 **IPv6**이다.

```
192.168.0.15                          //IPv4
2001:0db8:85a3::8a2e:0370:7334        //IPv6
```

IPv6는 128비트의 크기를 가지며, 16비트씩 8개의 그룹으로 나누어 16진수로 표기하고 점 대신 콜론(`:`)으로 구분한다. 0이 연속으로 나오는 부분은 `::`으로 줄여 쓸 수 있다. 다만 아직은 **IPv4가 훨씬 많이 쓰여서**, 당분간은 둘이 함께 쓰인다.

## 6. IP를 확인하는 명령어

### 윈도우

```
ipconfig
```

윈도우 명령 프롬프트에서 이 명령어를 치면 결과가 나온다. `IPv4 주소` 항목이 내 사설 IP이다. 집에서 공유기를 쓰고 있다면 보통 `192.168`로 시작한다. 공인 IP는 브라우저에서 "내 아이피"를 검색하면 바로 나온다.

### 우분투

```
ip a
```

`inet` 뒤에 나오는 것이 IP 주소이다.

```
curl ifconfig.me
```

우분투에서는 이 명령어를 치면 공인 IP를 확인할 수 있다.

## 7. 보안에서 IP 주소가 중요한 이유

### 1. 공격의 출발점이 IP다

공격자가 목표를 정하려면 먼저 **어디를 공격할지** 알아야 한다. 그 "어디"가 IP 주소다. 그래서 해킹의 첫 단계는 목표의 IP를 알아내는 일이다.

### 2. 공인 IP는 인터넷에 드러나 있다

내가 어떤 사이트에 접속하면, 그 사이트는 나의 **공인 IP를 알게 된다.** 반대로 서버의 공인 IP도 누구나 알 수 있다. 숨길 수 없는 정보라는 것이다.

### 3. NAT는 방패 역할도 한다

밖에서 보이는 건 공유기의 공인 IP뿐이라서, NAT 덕분에 집 안 기기들은 밖에서 접근하기 어렵다. 다만 이것은 NAT의 **"부수 효과"** 이지 방화벽 같은 **"보안 장치"** 가 아니므로, "공유기를 쓰니까 안전하다"고 생각하면 안 된다.

### 4. 주소는 위조될 수 있다

패킷의 "보내는 주소"는 **공격자가 마음대로 적을 수 있다.** 이걸 IP 스푸핑이라고 한다. 그래서 로그에 남은 IP만 보고 범인을 단정할 수 없다.

### 5. IP에 대한 오해

"IP를 알면 집 주소까지 알아낸다"는 말은 사실이 아니다. IP로 알 수 있는 건 보통 통신사와 대략적인 지역(시·도 수준)까지이다. 정확한 위치는 통신사가 가진 가입자 정보를 봐야 알 수 있고, 그것은 수사기관이 법적 절차를 거쳐야만 가능하다.

## 정리

- IP 주소는 네트워크에서 기기를 찾아가기 위한 주소이고, 0~255 숫자 4칸(32비트)으로 이루어진다.
- IPv4 주소는 약 43억 개뿐이라 모자라서 사설 IP와 NAT로 나눠 쓴다.
- 공인 IP는 전 세계에 하나뿐이고, 사설 IP는 우리 집 LAN 안에서만 유효해서 겹쳐도 된다.
- 공유기는 NAT로 사설 IP를 공인 IP로 바꾸어 내보내고, 돌아온 응답을 원래 기기에게 전달한다.
- `127.0.0.1`은 "나 자신"을 뜻하는 특별한 주소이다.
- 공격은 목표의 IP를 알아내는 것에서 시작하고, 보내는 주소는 위조될 수 있다.

이번 편에선 네트워크의 주소인 IP 주소와, 공유기가 주소를 바꿔주는 NAT를 알아보았다. 그런데 내 컴퓨터는 받는 주소만 보고 "이게 우리 집 안인지, 밖인지"를 어떻게 구분할까? 다음 편에선 그 기준이 되는 **서브넷 마스크**와, 바깥으로 나가는 문인 **게이트웨이**, 그리고 IP를 자동으로 나눠 주는 **DHCP**를 다룬다.
