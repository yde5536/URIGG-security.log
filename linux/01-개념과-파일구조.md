# 리눅스 제로부터 #1 - 개념과 파일 구조

## 리눅스란 무엇인가? 왜 배워야 하는가?

리눅스는 **운영체제(OS)** 이다. 운영체제는 컴퓨터 하드웨어를 관리하고 응용 프로그램이 원활히 실행되도록 돕는 소프트웨어이다. 컴퓨터는 하드웨어(모니터, 키보드, CPU, 메모리 등)끼리 서로 대화할 줄 모른다. 그 사이에서 "너는 이걸 하고, 넌 저걸 해"라고 **교통정리**를 해주는 프로그램이 운영체제이다. 예를 들어 윈도우, 맥OS, 안드로이드, iOS 등이 있다. 리눅스도 그중 하나이다.

### 그런데 리눅스는 왜 이름이 여러 개인가?

리눅스는 다양한 버전이 있다. 우분투, 칼리, 데비안, 민트 등등. 리눅스는 핵심 엔진만 무료로 공개되어 있다. 이 엔진을 **"커널"** 이라고 부르는데, 이것은 누구나 다 가져다 쓸 수 있다. 그래서 여러 단체나 회사가 이 엔진을 가져다가 자기 입맛에 맞게 만들어 완성품으로 내놓는데, 이것을 **배포판** 이라고 한다. 자동차로 비유하면 이렇다.

- **커널** = 엔진
- **우분투** = 그 엔진을 얹은 경차
- **데비안** = 같은 엔진을 쓴 트럭
- **칼리** = 같은 엔진을 쓴 SUV

**엔진이 같으니, 운전법도 비슷하다.** 우분투에서 배운 명령어는 칼리에서도 그대로 통한다. 반면 윈도우는 마이크로소프트에서 완성품으로 파는 거라 종류가 나뉘지 않는 것이다.

### 윈도우랑 무엇이 다른가?

#### 1. 무료이고 속을 뜯어볼 수 있다

윈도우는 돈을 주고 구매해야 하고, 내부를 열어볼 수 없다. 반면 리눅스는 무료이고 설계도가 모두 공개되어 있다. **"이게 왜 이렇게 동작하지?"** 라는 질문이 떠오를 때 직접 열어볼 수 있다는 것이다.

#### 2. 마우스보다 텍스트로 조작한다

윈도우는 바탕화면의 아이콘을 클릭하여 사용하는 것이 기본이다. 반면 리눅스는 검은 화면(터미널)에 명령어를 타이핑하여 사용하는 것이 기본이다. 이것의 가장 큰 이점은 **자동화** 이다. 예를 들어 폴더에 사진이 1000장 있다고 해보자. 윈도우는 이 사진들의 이름을 바꾸기 위해 전부 하루 종일 하나하나 노가다로 바꿔야 한다. **그러나 리눅스에서는 명령어 한 줄이면 3초 만에 바꿀 수 있다.**

#### 3. 이 세상의 서버는 대부분 리눅스이다

내가 리눅스를 공부하는 이유가 바로 이것이다. 네이버, 구글, 다음 등 우리가 접속하는 대부분의 서버는 리눅스로 돌아간다. **해킹은 결국 이 서버를 점검하는 일이라 상대를 알려면 리눅스를 배워야 한다.**

### 그렇다면 왜 서버로 리눅스를 쓰는 것인가?

일단 이 질문을 해결하기 위해선 **서버가 무엇인지** 알아야 한다. 서버는 **요청을 받으면 응답하는 컴퓨터** 이다. 내가 유튜브에 접속해서 "이 영상 보여줘"라고 했을 때 유튜브 서버는 내가 요청한 영상을 보내준다. 이 응답하는 쪽의 컴퓨터를 서버라고 한다. 그럼 그 서버는 일반 우리가 사용하는 컴퓨터와 무엇이 다를까? 답은 사용하는 방식이다.

- 내 노트북은 사용할 때만 켜지만, **서버는 1년 365일 항상 켜둔다.**
- 내 노트북은 화면과 키보드가 붙어있지만, **서버는 화면과 키보드 없이 선반에 끼워져 있다.**
- 내 노트북은 내가 직접 조작하지만, **서버는 원격으로 멀리서 조작한다.**
- 내 노트북은 고작 1대지만, **서버는 수천수만 대가 기본이다.**
- 내 노트북은 멈추면 좀 짜증날 뿐이지만, **서버는 멈추면 회사가 돈을 잃는다.**

이 차이 때문에 서버에서 요구하는 것이 달라진다.

#### 1. 재부팅하지 않아도 된다

윈도우가 업데이트할 땐 항상 재시작이 필요하다. 내 노트북이 업데이트한다면 5분 기다리면 그만이지만, 만약 은행 서버가 업데이트한다고 5분 멈춰버리면 그 사이에 일어나는 이체는 전부 실패한다. 만약 쇼핑몰 서버가 블랙프라이데이에 멈춰버린다면 손실액이 수십억이 넘을 것이다. **그러나 리눅스는 대부분의 업데이트를 재부팅 없이 서버를 끄지 않고 적용할 수 있게 설계되어 있다.** 심지어는 커널도 무중단으로 교체하는 기술이 있다고 한다. 몇 년씩 꺼지지 않고 돌아가는 서버가 흔하다.

#### 2. 화면 없이도 돌아간다

윈도우는 화면도 운영체제의 일부이다. 바탕화면을 그리는 데 CPU, 메모리를 계속 사용한다. 그러나 리눅스는 그래픽 화면이 선택사항이다. 서버용으로 설치하면 아예 없애버린다. 그러면 모든 자원이 요청에 응답하는 데만 쓰여 그래픽 화면을 그리는 데 들이는 자원을 줄일 수 있다. 숫자로 보면 차이가 확 나는데, 윈도우 서버는 메모리 2GB를 시작부터 먹고 들어간다. 그러나 리눅스 서버는 200MB 정도면 된다. 남은 메모리를 모두 서비스에 쓸 수 있다는 것이다.

#### 3. 돈이 들지 않는다!

윈도우 서버는 대당 라이선스 비용을 지불해야 한다. 게다가 접속자 수에 비례하여 추가비용이 발생한다. 서버 1대라면 별거 아니지만 앞서 언급했듯이 서버는 대부분 수천 ~ 수만 대이다. 그러나 리눅스는 0원이다!

#### 4. 원격 조작이 기본이다

서버는 데이터센터에 있고, 나는 사무실에 있다. 서버를 조작하려면 원격으로 접속해야 한다. 윈도우 방식은 상대 화면을 통째로 영상처럼 받아와야 한다. 따라서 데이터가 매우 무겁고 느리다. **리눅스 방식은 텍스트만 주고받기 때문에 데이터가 극도로 가볍다.** 지구 반대편에서도 원활히 접속할 수 있다.

#### 5. 자동화가 가능하다

서버가 1대면 손으로 해도 된다. 그러나 서버가 1000대라면 불가능하다. 리눅스는 모든 것이 "텍스트 명령"이기 때문에, **그 명령을 파일에 적어두면 그대로 자동 실행된다. 이것을 스크립트라고 부른다.** 예를 들어 서버 1000대에 보안 패치를 받아야 한다면 윈도우는 3분 × 1000대 = 50시간이 걸린다. 그러나 리눅스는 스크립트로 한 줄 실행하면 10분 정도 걸린다. 이것이 리눅스가 서버 시장을 장악한 가장 실용적인 이유라고 볼 수 있다.

#### 6. 내부를 볼 수 있으니 고칠 수 있다

윈도우에서 이상한 문제가 생기면 마이크로소프트가 고쳐 줄 때까지 기다려야 한다. 그러나 리눅스는 내부가 모두 공개되어 있기 때문에 **원인을 직접 추적하고, 급하면 스스로 고칠 수 있다.** 대형 회사들은 실제로 자기 상황에 맞게 리눅스를 고쳐 쓴다.

#### 얼마나 쓰이는가?

- 웹서버의 80%가 리눅스이다.
- 클라우드에서 돌아가는 대부분의 가상서버가 리눅스이다.
- 전 세계 슈퍼컴퓨터 상위 500위까지 전부 리눅스이다.
- 안드로이드도 속은 리눅스이다.

### 그래서 보안에서 왜 중요한가?

모의해킹의 목표물은 대부분 서버이다. 웹사이트를 점검한다는 것은 그 사이트가 돌아가는 서버를 점검하는 것이고, 그 서버는 대부분 리눅스이다. 리눅스를 모르면 침투에 성공해도 **그 안에서 뭘 해야 할지 모른다.** 책을 폈는데 글을 몰라 못 읽는 것이다. 반대로 리눅스를 잘 알면 공격과 방어를 동시에 이해하게 된다. 이것이 보안 분야에서 리눅스를 기초 중의 기초로 치는 이유이다.

## 리눅스의 구조

**파일 구조, 경로, 권한, 사용자** 이 네 개가 리눅스 기초의 뼈대이고, 마지막 두 개가 보안의 핵심이다. 오늘은 파일 구조와 경로에 대해서까지만 공부해보자.

### 1. 파일 구조

윈도우는 이렇게 생겼다.

```
C 드라이브 - 프로그램들
D 드라이브 - 내 파일들
E 드라이브 - USB
```

**리눅스는 드라이브 개념이 아예 없다.** 대신 딱 하나의 출발점이 있고, 모든 파일이 그 출발점에서 가지를 친다.

```
/
├── home                   // 사용자들의 개인 폴더
│   └── urigg              // 내 폴더
│       ├── 문서
│       └── 사진
├── etc                    // 설정 파일들
├── var                    // 로그
├── usr                    // 프로그램
├── bin                    // 기본 명령어들
└── tmp                    // 임시 파일
```

맨 위 `/` 하나가 나무뿌리라는 뜻의 "루트"이다. USB를 꽂으면 새 드라이브가 생기는 것이 아니라 이 나무의 어딘가에 가지로 붙는다.

### 2. 경로

파일이 어디 있는지 표현하는 방식이 **"경로"** 이다. 윈도우는 `\` 를 사용하고, 리눅스는 `/` 를 사용한다.

```
윈도우 : C:\Users\urigg\사진\고양이는세계제일.jpg
리눅스 : /home/urigg/사진/고양이는세계제일.jpg
```

같은 방식이다. 경로에는 두 가지 방식이 있는데, 이걸 구분하는 게 중요하다.

**절대경로** - 루트부터 전부 다 적기

```
/home/urigg/사진/고양이는세계제일.jpg
```

어디서 부르든 항상 같은 위치를 가리킨다. **주소를 도로명주소로 표기하는 것**과 같다. 항상 `/` 로 시작한다.

**상대경로** - 지금 위치 기준으로 적기

```
사진/고양이.jpg
```

내가 `/home/urigg`에 있을 때만 가능하다. **주소를 현 위치에서 두 블록 앞 은행 맞은편**이라고 하는 것과 같다.

#### 상대경로에서 알아야 할 기호들

상대경로 표기에선 알아야 할 기호가 4개 있다.

- `.` = 지금 이 폴더
- `..` = 한 단계 위 폴더 (상위 폴더)
- `~` = 내 홈 폴더 (`/home/urigg` 의 줄임)
- `/` = 루트

## 정리

- 리눅스는 **운영체제** 이고, 커널이라는 엔진에 각각 다른 차체를 씌운 것이다.
- 서버 대부분이 리눅스라서, 보안을 알려면 리눅스를 알아야 한다.
- 모든 파일은 `/` (루트) 하나에서 뻗어가는 구조이다.
- 경로에는 루트부터 전부 적는 절대경로와, 현재 위치 기준인 상대경로가 있다.
