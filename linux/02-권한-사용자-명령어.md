## 리눅스의 구조 - 이어서

1편에서 본 네 뼈대 중, 남은 **권한**과 **사용자**를 마저 본다. 이 둘이 보안의 핵심이다.

### 3. 권한

리눅스는 **모든 파일에 "누가 뭘 할 수 있는지"가 붙어있다.** 이게 리눅스 보안의 주요 부분이고, 해킹의 많은 부분이 이 권한을 어기거나 훔치는 일이다. 나중에 후술할 `ls -l` 명령어를 치면 권한이 보인다.

```
urigg@ubuntu:~$ ls -l
-rw-r--r-- 1 urigg urigg 1024 9월 20 18:00 비밀일기.txt
-rwxr-xr-x 1 urigg urigg 8192 9월 20 18:01 프로그램
```

일단 다른 부분은 제쳐두고 권한 부분인 `-rw-r--r--` 과 `-rwxr-xr-x` 부분만 봐보자. 이 권한이 보기엔 복잡해 보이지만, 알고 보면 꽤 쉽다. 규칙은 10칸을 나눠 읽는 것이다.

#### 권한 10칸 나눠 읽기

```
-  rw-  r--  r--
│   │    │    │
│   │    │    └── 나머지 모든 사람
│   │    └─────── 같은 그룹 사람
│   └──────────── 주인
└──────────────── 종류 (-는 파일, d는 폴더)
```

권한은 **한 자리 / 세 자리 / 세 자리 / 세 자리** 4개 조각으로 구분해 읽으면 된다. 앞 한 자리는 종류를 의미한다. `-` 는 파일을 의미하고, `d` 는 폴더를 의미한다. 그 뒤부터 이어지는 3자리 묶음은 `r` , `w` , `x` 순서로 기입된다.

#### 권한을 구성하는 알파벳의 의미

- **`r` 은 read(읽기)라는 뜻** 이다. 파일의 경우 이 파일을 열람할 권한, 폴더의 경우 목록을 볼 수 있는 권한이다.
- **`w` 은 write(쓰기)라는 뜻** 이다. 파일의 경우 이 파일을 수정할 권한, 폴더의 경우 파일 추가와 삭제가 가능한 권한이다.
- **`x` 은 execute(실행)라는 뜻** 이다. 파일의 경우 프로그램을 실행할 권한, 폴더의 경우 폴더 안에 들어갈 수 있는 권한이다.
- **`-` 는 공백이라는 뜻** 이다. 해당하는 위치의 권한이 없을 경우 `-` 로 표기한다.

#### 예시 다시 읽어보기

```
-rw-r--r--  비밀일기.txt
```

맨 앞자리가 `-` 이므로 이것은 파일이라는 것이고, 주인의 권한은 `rw-` 이므로 주인은 이 파일을 읽고 쓰는 것이 가능하다. 같은 그룹의 사람들은 권한이 `r--` 이므로 읽는 것만 가능하다. 동일하게 나머지 사람들도 권한이 `r--` 이므로 읽는 것만 가능하다.

**>> 내 일기를 다른 사람들이 볼 수 있는 상태이다.** 보안상 좋지 않다.

```
-rwxr-xr-x  프로그램
```

맨 앞자리가 `-` 이므로 이것은 파일이라는 것이고, 주인의 권한은 `rwx` 이므로 주인은 이 파일을 읽고 쓰고 실행이 가능하다. 같은 그룹의 사람들은 권한이 `r-x` 이므로 읽고 실행만 가능하다. 동일하게 나머지 사람들도 권한이 `r-x` 이므로 읽고 실행만 가능하다.

**>> 정상적인 프로그램의 모습이다.**

#### 권한은 숫자로도 표현한다

권한을 숫자로 표현하는 방법이 있다. 이게 더 간편해서 이게 더 자주 쓰인다.

- **`r` (읽기)** = 4
- **`w` (쓰기)** = 2
- **`x` (실행)** = 1
- **`-` (공백)** = 0

이걸 더해서 표기한다.

```
rwx = 4 + 2 + 1 = 7
rw- = 4 + 2 + 0 = 6
r-x = 4 + 0 + 1 = 5
r-- = 4 + 0 + 0 = 4
```

나중에 후술할 권한을 바꾸는 명령어인 `chmod` 를 사용하여 설명해 보겠다. `chmod 644 비밀일기.txt` 라고 하면 `rw-r--r--` 가 된다. `chmod 600`이면 `rw-------` , 즉 **나만 보고 수정할 수 있는 상태**가 된다. 비밀일기라면 이 권한이 맞을 것이다.

### 4. 사용자

리눅스는 원래 대형 컴퓨터 한 대를 여러 연구원이 나눠 쓰던 시절에 개발되어서 **여러 사용자가 한 컴퓨터를 동시에 사용하도록** 설계되었다. 그래서 사용자 개념이 엄격하다.

#### 일반 사용자

일반 사용자는 본인 홈 폴더 (`/home/이름`)에서만 자유롭게 활동할 수 있다. 시스템 파일은 건드릴 수 없고 평소엔 이 계정으로 활동한다.

#### root(관리자)

관리자는 **모든 권한을 가진다.** 시스템 파일 수정, 삭제, 프로그램 설치, 사용자를 추가하는 것 등이 가능하다. 심지어는 명령어 한 줄로 모든 시스템을 지우는 것도 다 가능하다.

#### sudo - 잠깐 관리자 되기

그래서 평소엔 일반 사용자로 있다가 필요할 때 잠시 관리자의 권한을 빌려온다. 이것이 `sudo` 명령어이다. 예시로 하나 살펴보겠다.

```
urigg@ubuntu:~$ apt install nmap
권한이 없습니다

urigg@ubuntu:~$ sudo apt install nmap
[sudo] urigg의 암호:
설치를 시작합니다...
```

`sudo` 를 앞에 붙이면 비밀번호를 물어보고, 맞으면 **그 한 줄만** 관리자 권한으로 실행된다. 우리가 윈도우에서 프로그램을 설치할 때 뜨는 "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?" 창과 같은 개념이다.

#### 왜 항상 root로 사용하지 않는 것인가?

이게 되게 편해 보이지만 그만큼 위험하다. 먼저 **실수 한 번이 치명적이다.** 오타 한 번으로 시스템이 전부 날아갈 수 있으니 당연히 위험하다. 두 번째로 **해킹당하면 그 즉시 모든 권한이 빼앗긴다.** 일반 사용자로 있으면 공격자가 들어와도 홈 폴더까지만 들어올 수 있고 거기서 관리자 권한을 얻으려고 애써야 할 것이다. **즉, 평소에 일반 사용자로 사용하는 것 자체가 방어하는 것이다.**

## 명령어

리눅스 명령어는 전부 같은 모양으로 생겼다.

```
명령어  -옵션  대상
   │      │     │
   ls    -l   /home
```

명령어는 **무엇을 할지**, 옵션은 **어떻게 할지**, 대상은 **어디에 할지** 이다. 대상을 생략하는 경우 보통 지금 위치에 진행한다. `-l`처럼 짧은 옵션은 붙여 쓸 수 있다. `-l -a` 와 `-la` 는 같은 옵션이다.

### pwd - 나 지금 어디야?

`pwd` 는 **print working directory**의 약자이다. 현재 위치를 **절대경로**로 알려준다.

```
urigg@ubuntu:~$ pwd
/home/urigg
```

가장 단순한 명령어지만 은근히 자주 쓴다. **길을 잃었을 때 치는 명령어**이다.

### ls - 여기 뭐 있어?

`ls` 는 **list**의 약자이다. 폴더의 내용물을 보여준다. 이것도 자주 쓰는 명령어이다.

```
urigg@ubuntu:~$ ls
문서 사진 다운로드
```

그냥 `ls` 만 치면 이름만 나열한다. 옵션을 붙이면 정보가 늘어난다.

#### 꼭 알아야 할 옵션들

**`-l` (long) - 자세히**

```
urigg@ubuntu:~$ ls -l
-rw-r--r-- 1 urigg urigg  1024  9월 20 18:00  비밀일기.txt
drwxr-xr-x 2 urigg urigg  4096  9월 19 22:10  사진
```

한 줄만 뜯어보겠다.

- `-rw-r--r--` 아까 보았던 종류 + 권한이다.
- `1` 링크 수를 표기하는 것이다. 지금은 크게 신경 쓰지 않아도 된다.
- `urigg` **주인의 이름**을 표기한다.
- `urigg` **소속된 그룹**을 표기한다.
- `1024` 크기를 바이트로 알려준다.
- `9월 20 18:00` 마지막 수정 시각이다.
- `비밀일기.txt` 이름이다.

두 번째 줄 맨 앞은 `d` 인데, 앞서 설명했듯이 폴더(directory)라는 의미이다.

**`-a` (all) - 숨긴 것까지**

리눅스에서는 **이름이 점(`.`)으로 시작하면 숨김 파일**이 된다.

```
urigg@ubuntu:~$ ls
문서  사진

urigg@ubuntu:~$ ls -a
.  ..  .bashrc  .ssh  문서  사진
```

`-a`를 붙이니 갑자기 뭔가 더 나왔다. **설정 파일들은 평소에 안 보이게 숨겨놓는다.** 여기서 보이는 `.` 과 `..` 은 앞서 설명한 **현재 폴더**와 **상위 폴더**이다.

**`-h` (human-readable) - 읽기 쉽게**

```
ls -l  >> 1048576
ls -lh >> 1.0M
```

`-l` 과 같이 쓴다. 바이트 숫자를 KB, MB로 바꿔준다.

### cd - 이동

`cd` 는 **change directory**의 약자이다. 폴더를 옮겨 다니는 명령어이다.

```
urigg@ubuntu:~$ cd 사진
urigg@ubuntu:~/사진$
```

프롬프트의 주소 부분이 바뀌는 것으로 이동을 확인할 수 있다.

#### 자주 쓰는 형태

- `cd 사진` 사진 폴더로 들어가는 것이다.
- `cd ..` **한 단계 위로, 상위 폴더로 올라가는 것**이다.
- `cd ../..` 두 단계 위로 올라가는 것이다.
- `cd ~` 또는 그냥 `cd` 홈 폴더로 이동하는 것이다.
- `cd /etc` 내가 원하는 절대경로를 입력하고 그 위치로 바로 이동하는 것이다.
- `cd -` **직전에 있던 경로로 바로 이동**하는 것이다.

### chmod - 권한 바꾸기

아까 보았던 권한을 바꾸는 그 명령어이다. **change mode**의 약자이다.

#### 숫자 방식

```
urigg@ubuntu:~$ ls -l 비밀일기.txt
-rw-r--r-- 1 urigg urigg 1024 9월 20 18:00 비밀일기.txt

urigg@ubuntu:~$ chmod 600 비밀일기.txt
urigg@ubuntu:~$ ls -l 비밀일기.txt
-rw------- 1 urigg urigg 1024 9월 20 18:00 비밀일기.txt
```

`r--r--` 가 `------` 로 바뀌었다. **이제 나만 볼 수 있다.**

#### 문자 방식

```
chmod +x 스크립트.sh      // 실행 권한 추가
chmod -w 중요파일.txt     // 쓰기 권한 제거
chmod u+x,go-w 파일       // 주인에겐 실행 권한 추가, 그룹과 나머지에겐 쓰기 권한 제거
```

- **`u` = user(주인), `g` = group(그룹), `o` = other(나머지), `a` = all** 을 의미한다.
- **`+` = 추가, `-` = 제거** 를 의미한다.

### cat - 파일 내용 보기

```
cat 비밀일기.txt
```

짧은 파일을 통째로 화면에 뿌린다. 긴 파일은 `less 파일명` 을 쓰면 스크롤할 수 있다. (`q` 로 나감)

### mkdir - 폴더 만들기

`mkdir` 는 **make directory**의 약자이다.

```
mkdir 새폴더이름
```

### rm - 삭제

`rm` 은 **remove**의 약자이다.

```
rm 파일     // 파일 삭제
rm -r 폴더  // 폴더 통째로 삭제
```

**리눅스에는 휴지통이 없다.** `rm` 으로 지우면 복구가 불가능하다. 특히 `rm -rf` 는 확인 없이 강제로 다 지우는 것이므로 **경로를 잘못 쓰면 복구 불가다.**

### cp/mv - 복사/이동

`cp` 와 `mv` 는 각각 **copy**와 **move**의 약자이다.

```
cp 원본 사본
mv 원본 새이름
```

### man - 설명서 보기

`man` 은 **manual**의 약자이다.

```
man ls
```

모든 명령어의 공식 설명서가 내장되어 있다. 옵션이 기억 안 날 때 사용하면 좋다. `q` 로 빠져나온다.

## 정리

- 리눅스의 권한은 파일마다 **주인, 그룹, 나머지**에게 `r`(read), `w`(write), `x`(execute)로 각각 부여된다.
- 권한의 숫자 표기로는 `r` = 4, `w` = 2, `x` = 1을 더해 표기한다.
- 평소엔 일반 사용자로 지내다 필요할 때 `sudo` 로 잠깐 관리자 권한을 빌린다. 이게 곧 방어다.
- 명령어는 `명령어 -옵션 대상` 구조로 이루어진다.
- 명령어는 크게 넷이다 — **위치 파악**(`pwd`·`ls`·`cd`), **파일 다루기**(`cat`·`mkdir`·`cp`·`mv`·`rm`), **권한**(`chmod`), **도움말**(`man`).

다음 편에서는 **실습 환경(WSL·TryHackMe)** 을 열어 오늘 배운 명령어를 하나씩 두드려본다.
